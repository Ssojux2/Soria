Classifying five thousand tracks

Soria indexes and analyses a local library but gives you nowhere to say what a track is. This is the redesigned Library: a crate tree, a table that shows the attributes you sort by, and a panel that lets you set them. Every number below is live against a 5,004-track library.

02 — Decisions

Why it looks like this

Colour
The chrome is monochrome so the track colours are the only hues on screen.

In a tool whose job is colour-coding, a coloured button competes with the data. Selection is a warm bone rail; status is a filled or hollow dot, never a green pill. The eight label colours are identical in both themes, because a red track has to be red on a laptop and on a projector.

Energy
Ten segments, read as length, not as a number to parse.

Derived from the mean of the analysed energy arc rather than its peak — nearly every dance track peaks near full somewhere, so a peak-based scale collapses the whole library to nines and tens and stops discriminating.

Mixed tags
A tag that only part of a selection carries gets its own state.

Rendering it as "off" would invite a click that strips the tag from the tracks that had it. The half-filled chip with a dash is the safeguard — see Dark and Perc in the panel above.

Four categories
Exactly four, renameable, fifty tags each.

rekordbox exposes exactly four My Tag categories, so four is what survives an export intact. It also keeps the grid hittable without reading. Enforced by the type system — there is no code path that produces a fifth.

Ownership
Ratings and tags live on the track row, never in the vendor mirror.

The Serato/rekordbox metadata table is a cache that gets rebuilt wholesale on every sync. Anything parked there would vanish the next time you pressed Sync Library. Imports seed empty fields and stop there — a value you set outranks every later import.

Suggestions
Nothing is applied without you accepting it.

Soria can score untagged tracks against the tracks you already tagged, which is the one thing rekordbox and Serato cannot do. That earns a proposal, not a write.
